    For powers like \(n=2\) or \(n=3\text{,}\) we have power functions representing the leading terms of quadratic or cubic functions.
    🔗
    For somewhat unusual powers of \(0 \le n \le 1\text{,}\) like \(n = \frac{1}{2}\) or \(n = \frac{1}{3}\) we have power functions like the square root or cube root, respectively. When using square roots, you may be more familiar with writing \(\sqrt{x}\text{,}\) but we can write \(g(x) = \sqrt{x} = x^{\frac{1}{2}}\text{.}\) Similarly for the cube root \(\sqrt[3]{x} = x^{\frac{1}{3}}\text{.}\) The root and fractional power are interchangeable, and the fractional powers are essential when doing calculus!
    🔗
    So, in addition to the squaring and cubing functions, the functions square root and cube root (and all of the others) are examples of power functions
    🔗
    You might encounter power functions in a variety of circumstances as models for physical phenomenon. For example,
    \begin{equation*} K = \frac{1}{2}mv^2 \end{equation*}
    describes the kinetic energy, \(K\text{,}\) for an object of mass \(m\) kilograms moving with velocity \(v\) meters per second. Treating \(m\) as a constant (for simplicity set \(m = 1\)), we can look at the relationship between \(K\) and \(v\) with a graph. What happens to the graph as we change \(m\text{?}\)
    🔗
    A related question that you might encounter in physics asks you to solve for \(v\) as a function of \(K\text{.}\)
    🔗

    Sometimes we encounter power functions with power, \(p\text{,}\) that is a number between 0 and 1, for example, when describing how some body measurement changes as a function of body size. In particular we look for relationships of the form
    \begin{equation*} (\text{output measurement}) = (\text{constant})(\text{input measurement})^\text{constant}. \end{equation*}
    A famous example relates a measure of metabolic rate, \(r\text{,}\) to body mass, \(m\text{,}\) using \(r = am^p\text{,}\) for numbers \(a\) and \(p\text{.}\) These are numbers that can be estimated from data to give a formula such as \(r = 0.06m^{0.77}\text{.}\) Of most interest, and significant historical debate, is that \(p \approx 0.75\) for most mammals.
    🔗
    Occasionally we need functions built by adding or subtracting multiple power function terms with different powers. When the powers are all nonnegative whole numbers, we call the result a polynomial. For example, we might need an \(n^{\text{th}}\)-degree polynomial, which can be written,
    \begin{equation*} \begin{aligned} p_n(x) &= \sum_{k = 0}^n a_kx^k\\ &= a_0x^0 + a_1x^1 + a_2x^2 + \dots + a_nx^n\\ \end{aligned} \end{equation*}
    🔗
    As a concrete example, here is an equation you might see in physics which describes the motion of an object in free fall, where \(s = s(t)\) is height in meters and \(t\) is time in seconds,
    \begin{equation*} s(t) = -4.9t^2 + 10t + 5. \end{equation*}
    In certain applications we are interested in describing the population growth rate, \(g\text{,}\) of an organism (e.g., the amount of animals produced over a given amount of time), as a function of the population size of that organism \(N\text{.}\) We might graph
    \begin{equation*} g = g(N) = rN\left(1-\frac{N}{K}\right), \end{equation*}
    where \(r\) and \(K\) are biologically-important numbers. Typically \(r\) is pretty small and \(K\) is pretty big. If it helps, we can pick \(r = 0.1\) and \(K=100\text{,}\) but let’s forge ahead first and just remember that these two letters represent numbers. If we get stuck, we can plug in these specific values and graph using a calculator

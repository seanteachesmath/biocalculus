    Section 2.3 Rules for derivatives

    Based on work done in Section 2.2 we can start to observe patterns and state rules for calculating derivatives directly, without the need for the definition for each new problem.
    🔗
    🔗

    Example 2.3.2. The derivative of a quartic.

    Using the limit definition and making use of Pascal’s Triangle to find coefficients in the necessary expansion of \((x+h)^{4}\text{,}\) we have,
    \begin{align*} f'(x) & = \lim\limits_{h\to0} \frac{f(x+h) - f(x)}{h}\\ & = \lim\limits_{h\to0}\frac{(x+h)^4 - (x^4)}{h}\\ & = \lim\limits_{h\to0}\frac{x^4+4x^{3}h + 6x^{2}h^2 + 4xh^{3} + h^{4}- x^4}{h}\\ & = \lim\limits_{h\to0}\frac{4x^{3}h + 6x^{2}h^{2} + 4xh^{3}+ h^4}{h}\\ & = \lim\limits_{h\to0}\frac{h(4x^{3} + 6x^{2}h + 4xh^{2} + h^{3})}{h}\\ & = \lim\limits_{h\to0}4x^{3} + 6x^{2}h + 4xh^{2} + h^{3}\\ f'(x) & = 4x^{3} + 6x^{2}(0) + 4x(0)^{2} + (0)^{3} = 4x^{3} \end{align*}

    🔗
    Interpreting the pattern in Table 2.3.3, it appears that for the numbers we have tested \(n = 2, 3, 4\) that to find the derivative of \(x^{n}\) we "multiply by the old power, then reduce the power by one". This is the power rule for derivatives.
    🔗

    Theorem 2.3.4. Power rule for derivatives.

    For a power function \(f(x) = x^{n}\) and any nonzero power \(n\text{,}\) the derivative is given by
    \begin{equation*} f'(x) = \dfrac{d}{dx}\Big(x^{n}\Big) = nx^{n-1}\text{.} \end{equation*}
    🔗
    🔗

    Proof.

    The proof is contained in the limit definition of the derivative. Recall that when we expanded \((x+h)^2\) we found \((x+h)^2 = 1x^2 + 2xh + 1h^2\text{,}\) and for \((x+h)^3 = 1x^3 + 3x^{2}h + 3xh^{2} + 1h^3\text{,}\) and finally, \((x+h)^4 = 1x^4 + 4x^{3}h + 6x^{2}h^{2} + 4xh^{3} + 1h^4\text{.}\) The first terms combine with the corresponding power of \(x\) that is subtracted in the numerator, and the term that remains has a coefficient that matches the order of the original power in the binomial expansion. Writing out the first few rows of Pascal’s Triangle might give you some more confidence in this pattern.
    🔗
    \begin{align*} f'(x) & = \lim\limits_{h\to0} \frac{f(x+h) - f(x)}{h}\\ & = \lim\limits_{h\to0}\frac{(x+h)^n - (x)^n}{h}\\ & = \lim\limits_{h\to0}\frac{x^n+nx^{n-1}h + \cdots + nxh^{n-1} + h^{n}- x^n}{h}\\ & = \lim\limits_{h\to0}\frac{nx^{n-1}h + \cdots + nxh^{n-1} + h^{n}}{h}\\ & = \lim\limits_{h\to0}\frac{h(nx^{n-1} + \cdots + nxh^{n-2} + h^{n-1})}{h}\\ & = \lim\limits_{h\to0}nx^{n-1} + \cdots + nxh^{n-2} + h^{n-1}\\ f'(x) & = nx^{n-1} + \cdots + nx(0)^{n-2} + (0)^{n-1} = nx^{n-1} \end{align*}
    In taking the limit as \(h \to 0\) all of the terms that still contain \(h\) vanish and all that remains is the term that only involves \(x\) but not \(h\text{.}\)
    🔗
    🔗
    To practice the mechanics of this rule, we can apply Theorem 2.3.4 to power functions.
    🔗

    Example 2.3.5. Using the power rule.

    Find derivatives of powers of \(x^{n}\) for \(n = 2, 3, 4\text{.}\)
    🔗
    Solution.

    (a)

    For \(x^{2}\text{,}\)
    \begin{equation*} \dfrac{d}{dx}\Big(x^{2}\Big) = 2x^{2-1} = 2x^{1} = 2x\text{.} \end{equation*}
    🔗
    🔗

    (b)

    For \(x^{3}\text{,}\)
    \begin{equation*} \dfrac{d}{dx}\Big(x^{3}\Big) = 3x^{3-1} = 3x^{2}\text{.} \end{equation*}
    🔗
    🔗

    (c)

    For \(x^{4}\text{,}\)
    \begin{equation*} \dfrac{d}{dx}\Big(x^{4}\Big) = 4x^{4-1} = 4x^{3}\text{.} \end{equation*}
    🔗
    🔗
    🔗
    🔗
    We can continue using power functions with less common powers.
    🔗

    Example 2.3.6. Using the power rule.

    Find derivatives of powers of \(x^{n}\) for \(n = -3, \frac{1}{2}, 17\text{.}\)
    🔗
    Solution.

    (a)

    For \(x^{-3}\text{,}\)
    \begin{equation*} \dfrac{d}{dx}\Big(x^{17}\Big) = 17x^{17-1} = 17x^{16} = 2x\text{.} \end{equation*}
    🔗
    🔗

    (b)

    For \(x^{3}\text{,}\)
    \begin{equation*} \dfrac{d}{dx}\Big(\sqrt{x}\Big) = \dfrac{d}{dx}\Big(x^{\frac{1}{2}}\Big) = \frac{1}{2}x^{\frac{1}[2]-1} = \frac{1}{2}x^{-\frac{1}{2}}\text{.} \end{equation*}
    🔗
    🔗

    (c)

    For \(x^{4}\text{,}\)
    \begin{equation*} \dfrac{d}{dx}\Big(x^{4}\Big) = 4x^{4-1} = 4x^{3}\text{.} \end{equation*}
